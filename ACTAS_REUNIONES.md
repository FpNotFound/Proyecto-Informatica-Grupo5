Revisar el avance de las tareas planificadas para el Sprint 1. 【1-fcc442】

- Arquitectura MVC definida y estructurada.

### Decisiones adoptadas

- Utilizar un único archivo JSON para usuarios.
- Mantener una arquitectura MVC estricta.
- Documentar las decisiones técnicas.
- Mejorar la planificación temporal del equipo. 【1-fcc442】
